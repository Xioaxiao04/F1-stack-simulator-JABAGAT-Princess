**Student:** JABAGAT, PRINCESS O.
**Section:** BSIT WMT -2-2

## Description
This project is a starter web application for learning how a stack works using HTML, CSS, Bootstrap, JavaScript, and jQuery.

## Stack Operations
- Push: Add an item to the top of the stack.
- Pop: Remove the top item.
- Peek: View the top item without removing it.
- Clear: Remove all items from the stack.

- JavaScript
- jQuery
